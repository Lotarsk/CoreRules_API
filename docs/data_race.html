Race.dat — Character races

Holds the character races — Human, Elf, Dwarf, and the rest — describing what each race requires, the modifiers it confers, and the physical stock used to generate a character of that race.

Data in this file includes

  • Name & Description — The name of the race and its prose description.
  • Lineage — Whether the race is a sub-race and, if so, the parent race it derives from.
  • Ability Score Ranges — The minimum and maximum score each ability (Strength, Dexterity, Constitution, Intelligence, Wisdom, Charisma) may take for the race.
  • Ability Adjustments — The fixed modifiers the race applies to each ability score.
  • Class Level Limits — The maximum level a member of the race may reach in each class group (fighter, mage, ranger, thief, bard, cleric, druid, specialist, paladin).
  • Allowed Classes — Which single-class and multi-class combinations the race may take.
  • Character Points — The starting, retained, and cost character-point values for the race under the Skills & Powers rules.
  • Thief Ability Modifiers — The racial percentage adjustments to the thieving skills (pick pockets, open locks, find/remove traps, move silently, hide in shadows, and the rest).
  • Combat & Movement — Natural armor class, bonus hit points, a natural attack, and the unencumbered movement, swimming, and flying rates.
  • Flags — The race's yes/no properties: whether it is a Core Rules race, allows dual-classing, allows exceptional Strength, may add +1 to any score, and so on.
  • Alignment Allowances — Which alignments a member of the race may be.
  • Languages & Skills — The languages the race speaks and the racial abilities (skills) it grants.
  • Saving Throws — The saving-throw bonuses the race confers, derived from its racial abilities.
  • Anatomy — The number of hands the race has.
  • Physical Stock — The height, weight, and starting age used in character generation, given per gender with the dice rolled to vary them.
  • Portrait Images — The picture file (and its directory) and the lists of male and female portrait images available for the race.
