◆ GetImageLocation()

virtual ImageLoc CoreRules::IPart::GetImageLocation ( ) const
pure virtual

Resolve this part's image bitmap into an absolute path and optional sprite-sheet offset.

Decodes the image_bitmap field against the platform config:

  • empty / not set -> { path="", index=-1 }
  • CRE_<name> -> custom bitmap in userbmp; index = -1 (single-image file)
  • numeric (e.g. "127") -> sprite-sheet bitmap in bitmaps_equip; path is the containing sheet (E001_050.BMP, E051_100.BMP, ..., E651_700.BMP) and index is the 0..49 offset within that sheet.

Returned by value; caller owns the struct. Safe to call before LoadDatabases() – the config is read independently.
