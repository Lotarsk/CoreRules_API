Detailed Description

Escort / per-item monster entry inside an encounter template's Item-Properties row.

Body layout: 4 LONGs for Number-Appearing dice (N, S, M, A) followed by an embedded IMonsterOb (full stat block). The dice tell the encounter generator how many of the embedded monster appear; the monster itself is by-value (mutated via the interface pointer returned from GetMonster()).
